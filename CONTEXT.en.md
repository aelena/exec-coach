# CONTEXT — Executive Reflexes / Corporate Kata Gym

## Why this exists
This app emerged from a Socratic dialogue about Albert Bandura's self-efficacy and executive reflexes: the ability to detect unvalidated premises, business contradictions, incentives, political risks and elephants in the room **in real time**, then intervene firmly without needlessly threatening others' dignity. The initial trainee is an experienced CTO and technical advisor who already has strong technical judgment and wants to develop spontaneous executive communication, brevity, strategic breadth and political awareness. **The goal is not compliance or excessive politeness; it is influence without loss of rigor.**

## Lessons from the original exercises
- A six-week promise of a complete AI assistant without an evaluation set or acceptance criteria requires separating the commercial commitment from the technical conditions for responsible delivery.
- A sound response can refuse an unsupported guarantee while offering a verifiable limited delivery, subject to contractual realities.
- Automating 200,000 hours does not automatically mean realized cash savings; distinguish released capacity, avoided hiring, demand and redeployment strategy.
- A technical advisor need not publicly challenge every CEO assumption; respect mandate, document unvalidated assumptions and choose escalation channels wisely.
- 'How many tests did you write?' can sound like an examination; 'what evidence do we need to ship Friday at acceptable risk?' frames a shared decision.
- A defensive reaction may reflect incentives and reputation, not necessarily the trainee's communication flaw.

## What to build
An installable, **voice-first, local-first, BYOK PWA without a proprietary backend**. Markdown-configured executive actors, independent coach LLM, short oral katas, deliberative writing mode, Easy/Medium/Hard, immediate/end-of-kata/Socratic feedback, editable power-question library, dashboard, A/B replay and local JSON sessions. Spanish and English from MVP, with **all distributed Markdown content and documentation translated into both languages**. Code, methods, schemas, IDs and tests remain English.

## Non-negotiable principles
1. Truth before niceness; diplomacy without factual compromise.
2. Strict separation between actor and coach, including private memory and rubrics.
3. Evidence-grounded coaching; multiple valid answers; no cosmetic rewriting.
4. Difficulty changes conditions, never the actor's identity.
5. Oral Walk is the principal training mode; Desktop trains deliberative writing.
6. Driving is low-demand listening/reflection only, no distracting interaction or pressure.
7. IndexedDB and JSON portability; no app backend or default cloud sync.
8. BYOK browser keys are not secure server-side secrets; disclose limitations.
9. Uniform, validated actor Markdown; separate scenario/coach/profile definitions.
10. Keep MVP lean: no agent frameworks, SaaS, accounts or addictive gamification.
11. Local Memory Manager has five scopes: short-term, long-term, entity, user and coach.
12. Coach judgment changes organically through evidence and conversation, not a dispute button.
13. Actors may recall only plausible observable history; never receive private SWOT.
14. Hidden scenario facts and causal twists are consistent, traceable and replay-stable.
15. Post-training causal debrief is conversational and **untimed**; do not pretend to reveal private LLM reasoning.
16. Long-running multiweek simulations belong to the roadmap.

## Instructions to the coding assistant
Read `CONTEXT.md` / `CONTEXT.en.md`, then `SPECS.md` / `SPECS.en.md`, bilingual docs and content templates. Follow SPECS v0.5 on conflicts; record technical deviations as short ADRs. Do not add a backend, remote database, login, agent framework or proxy without explicit approval. Build testable vertical slices, validate model JSON, isolate contexts, and keep code and contracts in English. Update Spanish and English documentation and prompt packs in the same change. Test browser-direct BYOK, microphone, TTS and Wake Lock on real iOS and Android devices. Do not claim reliable background audio or universal provider support. The first demonstrable outcome is a full oral kata with feedback, local memory and causal postmortem.
